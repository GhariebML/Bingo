# API Documentation

Base path: `/api/v1`

- `GET /health` - service health
- `POST /api/v1/chat` - mock supportive chat response
- `POST /api/v1/mood` - record mood entry
- `POST /api/v1/journal` - create journal entry
- `GET /api/v1/exercises` - list guided exercises
- `POST /api/v1/safety/check` - classify safety risk
